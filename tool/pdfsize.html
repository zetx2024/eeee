Coordinate System
Browser coordinates normally start at the top-left of the page.

PDF libraries such as pdf-lib use the bottom-left as the origin.

This tool therefore calculates both the browser position and the converted PDF coordinate.

The displayed JavaScript value is ready to use with:

page.drawText()
